# 과거 개발 자료

이 폴더는 이전 개발 명세, 설계안, 조사 자료와 작업 프롬프트를 보관한다.
작성 당시의 판단을 확인하기 위한 기록이며, 현재 구현이나 새 요구사항에 우선하는 개발 지침은 아니다.

- [대시보드 개발 명세](spec.md): 당시의 MVP 범위, 데이터 계약, 화면·테스트 요구사항
- [대시보드 시각화 계획](dashboard-visualization-plan.md): 화면 구성과 시각화·라이브러리 검토
- [서비스 벤치마크](dashboard-benchmark.md): 유사 서비스 조사와 당시의 차용·제외 결정
- [리포트 인사이트 작업 프롬프트](report-insight-next-step-prompt.md): 인사이트 백필 개발을 위한 당시의 작업 지시

고도화할 때는 현재 코드와 테스트를 먼저 확인하고, 새 요구사항과 충돌하는 내용은 그대로 적용하지 않는다.
이 폴더의 구현 지시나 프롬프트를 읽었다는 이유만으로 작업을 시작하지 않는다.
새로 합의한 설계는 `docs/`에 별도 문서로 작성하고, 참고한 과거 자료를 연결한다.
