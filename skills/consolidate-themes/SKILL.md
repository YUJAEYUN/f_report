# consolidate-themes

## 언제
태깅(summarize 또는 retag)이 있었던 실행에서, 브리핑/인사이트를 만들기 직전에 한 번.
tag-industry가 기존 테마명 재사용을 유도하지만, 리포트마다 따로 태깅하다 보면 같은
이슈가 다른 이름으로 갈라진다 (예: "ESS 수요" / "북미 ESS 성장"). 주간 인사이트의
테마 순위가 흩어지지 않도록 이를 대표 이름으로 합친다.

## 입력
- 최근 테마 목록과 각 테마의 리포트 수, 대표 리포트 제목 몇 개

## 처리절차
1. **같은 이슈를 가리키는 테마만** 묶는다. 관련 있지만 다른 이슈는 묶지 않는다.
   - 묶는 예: "ESS 수요" + "북미 ESS 성장", "AI 데이터센터 전력" + "데이터센터 전력 수요"
   - 묶지 않는 예: "미중 정상회담"과 "중국산 철강 규제"(다른 사건),
     "FOMC 금리 인상"과 "미국 10년물 5% 돌파"(연관되지만 별개의 사건/지표)
2. 대표 이름은 묶이는 이름 중 하나를 고른다. 더 넓고 리포트 수가 많은 쪽을 우선.
   새 이름을 만들지 않는다.
3. 확신이 없으면 묶지 않는다. 한 번 합친 건 되돌리기 번거롭다.

## 출력형식
`{"merge": {"합쳐질 테마": "대표 테마", ...}}` — 합칠 게 없으면 `{"merge": {}}`.
파이프라인이 `data/themes/aliases.json`에 누적하고, 모든 리포트의 themes와 이후
태깅 결과에 적용한다.
