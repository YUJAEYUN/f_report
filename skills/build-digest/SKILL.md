# build-digest

## 언제
파이프라인의 마지막 단계. 그날의 collect~tag가 끝난 뒤, 그리고
synthesize-industry-brief가 그 주기의 브리핑을 갱신한 뒤 실행한다.

## 입력
- 오늘 날짜의 `data/reports/{date}/*.json` (individual + daily_series 전부)
- 이번 주 갱신된 `data/industries/{industry}/briefs/{ISO주차}.md`

## 처리절차
1. **오늘의 데일리 코멘트** 섹션: 오늘 수집된 `daily_series` 리포트를 그대로
   요약해 얹는다 (별도 재가공 없이, 시리즈 자체가 이미 종합물이므로).
2. **산업별 브리핑 업데이트** 섹션: 오늘 갱신이 있었던 산업의 최신
   `briefs/{ISO주차}.md` 내용을 링크/요약으로 얹는다. 오늘 갱신이 없었던
   산업은 다이제스트에 억지로 포함하지 않는다.
3. **오늘의 개별 리포트 목록** 섹션: `individual` 리포트를 카테고리별로
   나열한다 (제목, 애널리스트, 산업 태그, 링크).
4. (선택, 스코프 아웃 아님 확인 필요) 완성된 다이제스트를 GitHub Discussions에
   자동 포스팅한다 — 별도 프론트엔드/GitHub Pages는 만들지 않는다.

## 출력형식
`digest/{date}.md`. 위 3개 섹션 구조를 고정하고, 각 섹션 안의 순서는
카테고리 → 산업명 알파벳/가나다 순으로 안정적으로 유지한다 (매일 순서가
바뀌면 diff가 지저분해짐).

## 주의사항
- daily_series와 individual을 한 목록에 섞어서 나열하지 않는다 (이중 카운트
  방지가 이 프로젝트의 핵심 제약 중 하나).
- 오늘 수집된 게 하나도 없으면 ("휴장일" 등) 빈 다이제스트를 커밋하지 말고
  건너뛴다.
