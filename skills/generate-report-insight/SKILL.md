# generate-report-insight

이미 요약된 개별 리포트에 **리서치 독자의 판단을 돕는 인사이트만** 생성한다.
기존 요약이나 분류를 다시 작성하지 않는다.

## 출력 관점

- `change`: 기존 전제와 비교해 무엇이 달라졌는지 쓴다. 원문에 비교 기준이
  없다면 과거 사실을 만들지 말고 현재 리포트가 강조한 변화를 쓴다.
- `implication`: 그 변화가 기업·산업·시장 흐름을 이해하는 데 왜 중요한지 쓴다.
- `watch_points`: 해석을 확인할 수 있는 구체적인 지표나 사건을 1~3개 쓴다.

세 필드는 **변화 → 의미 → 확인**의 한 흐름이어야 하며 기존 요약의 단순 반복을
피한다. 리포트 메타데이터, 기존 요약, 제공된 원문 안의 근거만 사용한다.

## 금지 사항

- 매수·매도 등 투자 추천이나 목표 수익률을 생성하지 않는다.
- 원문에 없는 사실이나 외부 최신 정보를 보태지 않는다.
- 근거가 없는 과거 상태나 비교 기준을 지어내지 않는다.
- 기존 `summary`, `desk`, `industries`, `themes`, `tagged_at`의 대체 값을 출력하지 않는다.
